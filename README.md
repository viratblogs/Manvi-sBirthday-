# 🎂 Manvi's Magical October Birthday

A cute, interactive, storybook-style birthday website — six animated scenes, a
recurring baby-panda guide, a flower-hunt mini-game, a dream journey, a birthday
celebration, and a heartfelt typewriter letter.

Built with plain **HTML, CSS and vanilla JavaScript** (no framework, no build
tooling required, no backend, no paid services).

---

## Quick start

**Option A — just share it (easiest):**
Open `manvi-birthday.html` in any web browser. It is a single self-contained file
with all CSS and JavaScript inside it, so it works from a file, an email
attachment, a USB stick, or any static host. This is the file to send.

**Option B — edit the code (linked project):**
Keep `index.html`, `styles.css` and `app.js` **in the same folder** and open
`index.html`. It loads the stylesheet and script from those files.

> Note: `index.html` will look blank/unstyled if it is opened without
> `styles.css` and `app.js` next to it. For sharing, use `manvi-birthday.html`.

No installation, no `npm install`, no server needed.

## Files

| File | What it is |
|------|------------|
| `manvi-birthday.html` | The finished site as one self-contained file (share this). |
| `index.html` | The page structure, for the editable linked project. |
| `styles.css` | All styling: palette, fonts, panda states, scene transitions, responsive rules. |
| `app.js` | All behaviour: panda rendering, scene engine, flower game, confetti, music, typewriter. |
| `markup.html` | The body markup fragment used by the build script. |
| `build.py` | Regenerates both `manvi-birthday.html` and `index.html` from the source files. |
| `README.md` | This file. |

There are no separate image or audio asset files — every illustration is inline
SVG and the music is generated live with the Web Audio API, so nothing can ever
show up as a broken image.

## Regenerating the single-file version

After editing `styles.css`, `app.js` or `markup.html`, rebuild both outputs:

```bash
python3 build.py
```

This rewrites `manvi-birthday.html` (everything inlined) and `index.html`
(linked) into the `output` folder. `build.py` uses only the Python standard
library.

## Deploying / sharing

Any static host works. A few options:

- **GitHub Pages** — commit `manvi-birthday.html` (or the linked files) to a
  repo, then enable Pages in Settings. You get a public link.
- **Netlify / Vercel / Cloudflare Pages** — drag-and-drop the folder; no build
  command is required (it is already static).
- **Google Drive / Dropbox** — upload `manvi-birthday.html` and share the link.
- **Email / WhatsApp** — just attach `manvi-birthday.html`.

For the best link previews when sharing, put the site online (the Open Graph
tags are already in the page) and, if you like, add a preview image.

## How it works (for editing)

- **Palette & fonts** — all colours are CSS custom properties at the top of
  `styles.css` (`:root { --peach, --pink, --lavender, --sage, --orange ... }`).
  Change them there to re-theme the whole site.
- **The panda** — one reusable SVG is injected into every `.panda` element by
  `app.js`. Expressions (sleeping, blinking, happy, dancing, clapping, waving)
  are switched with a `data-expr` attribute and CSS classes, so the character
  stays consistent everywhere.
- **Scenes** — each is a `<section class="scene" id="sceneN">`. Navigation
  buttons carry a `data-next="N"` attribute; the scene engine shows one at a
  time with a fade/slide transition.
- **Letter text** — edit the `LETTER` array in `app.js`.
- **Messages / compliments** — the `COMPLIMENTS` and `WISHES` arrays, and the
  text inside the talent cards in `markup.html`.
- **Music** — generated by the `Music` object in `app.js` (a soft pentatonic
  loop). It starts only after the first tap, and there is an on/off toggle.
- **Reduced motion** — users who prefer reduced motion get calmer animations and
  the letter appears instantly (honours `prefers-reduced-motion`).

## Accessibility & compatibility

- Large, touch-friendly buttons (56px tall on phones).
- Respects device safe areas (notch / home bar) on phones.
- Keyboard-focusable controls with visible focus outlines.
- `prefers-reduced-motion` supported.
- Works offline except for the Google Fonts stylesheet, which degrades
  gracefully to system fonts if it cannot load.

## Customising the recipient

This build is personalised for **Manvi**. To adapt it: search and replace
"Manvi" across `markup.html` and `app.js` (and the letter text in `app.js`),
then run `python3 build.py`.
